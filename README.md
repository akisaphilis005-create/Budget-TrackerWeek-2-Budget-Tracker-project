
# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application designed to help users record and monitor their daily expenses.

The project was developed using HTML and CSS.

## Project Files

### 1. index.html
This file contains the structure of the Budget Tracker.

It includes:
- Main heading and logo.
- Expense entry form.
- Category dropdown with five options.
- Expense table with five sample records.
- Collapsible instructions section.
- Embedded YouTube budgeting video.

### 2. style.css
This file controls the appearance of the application.

It includes:
- Background colors and text styling.
- Form and button styling.
- Expense table borders and colors.
- Alternating table row colors.
- Hover effects.
- Focus effects for form inputs.
- Responsive design for smaller screens.

### 3. Advanced CSS Selectors

The project uses the following advanced CSS selectors:

1. `input:not([type="date"])` - Selects inputs except date inputs.
2. `input:focus` - Changes the appearance of an input when selected.
3. `tr:nth-child(even)` - Styles even-numbered table rows.
4. `.expenses-section td` - Styles table data cells inside the expenses section.

## Technologies Used

- HTML5
- CSS3
- YouTube iframe embedding

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
